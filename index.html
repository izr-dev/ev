⬇ Download VotolApp+DriverPL2303.rar

1. EM_V3-40 (EM-2 series products).exe

Aplikasi utama di PC/laptop untuk melakukan konfigurasi, pengaturan parameter (seperti batas arus, kecepatan/RPM, throttle, dan regenerative braking), serta memantau status kerja controller Votol seri EM-2 secara langsung.

2. PL2303_Prolific_DriverInstaller_v110(2).exe

Installer driver USB-to-Serial untuk chip Prolific PL2303. Instal file ini terlebih dahulu agar sistem operasi Windows dapat mengenali kabel koneksi/USB-TTL dan menyediakan port COM saat menghubungkan laptop ke controller Votol.
